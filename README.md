# AI-Powered Security Operations Center (AI SOC)

Real-time IoT cyber threat detection system using Machine Learning and Explainable AI.

## Features

- Real-time threat monitoring
- IoT device simulation
- AI explainability dashboard
- SHAP-based feature importance
- Threat intelligence feed
- PDF report generation
- Security Operations Center UI
- Hybrid ML models:
  - Isolation Forest
  - Autoencoder
  - XGBoost

## Technologies Used

- Python
- Flask
- SQLite
- XGBoost
- TensorFlow
- SHAP
- HTML/CSS/JavaScript
- Chart.js

## Dashboard Modules

- Live Threat Feed
- Threat Analytics
- AI Explainability
- Device Monitoring
- Threat Console
- Downloadable Reports

## Installation

```bash
pip install -r requirements.txt
python app.py
```
